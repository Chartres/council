# Mastermind Council

Bring an idea — a business, a project, a decision you keep turning over. A council of historical
thinkers debates it among themselves for a few rounds, then returns a verdict and one next
action. Answer back and the debate continues.

**https://council.dravec.org** · free · no account for the first session

Seven thinkers, up to four at a time: Socrates, Marcus Aurelius and Seneca sit by default;
Buddha, Confucius, Benjamin Franklin and Maria Montessori are available. One shared question a
day, the same for everyone, with a result card you can share that carries the vote split and
never your own text.

Every persona is a fictional interpretation generated by an AI model from public-domain sources.
Not the words, opinions or endorsement of the real people or their estates, and not medical,
legal or financial advice. Not affiliated with any Montessori organisation.

## Run it

```bash
npm ci
npm run stub                                          # the fake gateway on :8787
VITE_GATEWAY_URL=http://localhost:8787 npm run dev    # http://localhost:5173
```

No Anthropic key lives here. The model runs in the gateway Worker (`llm.dravec.org`); this repo
only speaks its SSE contract. See `AGENTS.md` for the full build/test/release contract,
`DESIGN.md` for the visual rules, `docs/SUPABASE.md` for the one-time backend setup.

## Tests

```bash
npm run typecheck && npm test && npm run e2e
```

Unit tests cover the SSE parser, the date-keyed daily question, the share card and the idea
store. Playwright walks the three primary journeys at 390 px against the stub gateway and writes
screenshots to `e2e/shots/`.
